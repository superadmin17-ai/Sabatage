Sabatage Studio landing page

Open index.html in Chrome (double-click), or upload the whole folder to any web host
(Vercel, Netlify, S3). Keep the assets folder next to index.html.

The page picks its footage automatically:
  desktop  -> assets/video/desktop  (1080p-class, sharper)
  phones   -> assets/video/mobile   (540-720p, light on data)
Layout is fully responsive; one index.html serves both.
